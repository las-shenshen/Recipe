# 家的味道 · 家庭菜谱小程序

使用微信小程序原生框架编写的家庭菜谱。菜谱、每日点菜和买菜清单接入微信云开发：菜谱所有用户可查看和收藏，只有作者本人能编辑或删除；每日点菜和买菜清单所有用户可共同编辑。

## 在微信开发者工具中运行

1. 打开微信开发者工具，选择“导入项目”，项目目录选择本文件所在目录。
2. `project.config.json` 已配置小程序 AppID，云环境和部署说明见 `CLOUD_SETUP.md`。
3. 编译预览。

## 当前功能

- 浏览示例家庭菜谱，按口味筛选、搜索菜名或食材。
- 菜谱页按分类筛选；可新增自定义分类并同步给所有用户，没有菜谱的分类可由创建者删除。
- 收藏菜谱，查看详情、食材和分步做法；收藏页可查看“大家都在收藏”和“我收藏的”。
- 在菜谱详情选择采买套数，一键将按份数换算后的食材加入清单。
- 共享买菜清单可按菜谱查看，也可按食材合并相同项目；支持多人勾选、删除和清理已买项目，离线修改会在联网后自动同步。
- 录入自己的菜谱，包括分类、用时、份量、难度、是否“孩子爱吃”、食材和步骤；标记后会出现在首页“孩子爱吃”筛选里。
- 从菜谱或点菜计划加入共享清单，手动添加、勾选、删除或清理已买项目；本机旧清单经预览确认后导入，原副本保留。
- 每日点菜按日期共享三餐、份数和吃过记录，人人可添加、移除、标记或清空。页面打开时每 10 秒同步，也可下拉刷新。
- 本机旧菜单可在对应日期点击“共享本机旧安排”合并。

## 项目结构

- `app.js` / `app.json`：小程序入口、页面和底部导航。
- `pages/home`：菜谱首页。
- `pages/recipes`：完整菜谱列表。
- `pages/favorites`：收藏列表。
- `pages/detail`：菜谱详情。
- `pages/add`：菜谱录入。
- `pages/list`：采购清单。
- `pages/menu`：共享点菜和每周吃饭回顾。
- `pages/profile`：微信快捷登录、个人资料和常用入口。
- `cloudfunctions/recipeHub`：共享菜谱、收藏和自定义分类的读写。
- `cloudfunctions/accountHub`：微信身份校验与可选资料保存。
- `cloudfunctions/menuHub`：共享菜单读写及并发事务。
- `cloudfunctions/shoppingHub`：共享买菜清单读写、操作去重和并发事务。
- `utils/amount.js`：食材用量缩放和跨菜谱汇总。
- `custom-tab-bar`：底部导航。

账号与共享菜单回归验证：`node --test tests/account-hub.test.js tests/shared-menu.test.js`。

共享买菜清单回归验证：`node --test tests/shared-shopping.test.js`。

菜谱、收藏和分类回归验证：`node --test tests/recipe-hub.test.js`。
